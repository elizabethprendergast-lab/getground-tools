How to read this

  • Before = 8 Sep – 6 Oct 14:02 (4 weeks before the relaunch). Since = from the relaunch to now. Averages are per day so the two periods compare fairly.
  • 6 Oct 14:02 — new page live (free-setup hero, instant calculator, Set up today → checkout). 7 Oct 09:32 — Set up today now goes through app sign-up first.
  • Visits and clicks come from Mixpanel's warehouse copy, which can be up to a day behind, and only cover people who accepted cookies.
  • Plans bought counts Core/Complete Plans deals marked won in HubSpot: for form leads, bought after they submitted; for sign-ups, bought by the account created from this page.
  • Internal test clicks count too. Use utm_campaign=internal_test when testing so they can be spotted.
